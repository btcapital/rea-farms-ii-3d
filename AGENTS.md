# Rea Farms 3D project rules

- Preserve all source documents. Treat everything inside source_documents as read-only; do not modify, move, rename, or delete source files.
- Never invent missing building dimensions or details.
- Obtain approval of geometry before adding final finishes.
- Change only explicitly requested components.
- Save revisions separately; do not overwrite approved models.
- Give novice-friendly instructions, one step at a time, using exact menu or button names when possible.

Do not install software, download add-ons, publish anything, or change system settings without the user's approval.
